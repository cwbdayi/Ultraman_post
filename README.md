# 超人力霸王賽羅：宇宙決戰（V1.0）

16:9 橫式 4K 科幻電影 × 軍事情報海報，採用原創 SVG 向量繪圖，可離線預覽，也可由展示頁下載 3840 × 2160 PNG。

## 專案檔案
- `index.html`：展示網站（無外部 JavaScript 或 CSS 相依）
- `assets/poster.svg`：3840 × 2160 向量海報，包含主視覺、聲波圖、雷達圖、怪獸資料及武器卡
- `data/monster-intelligence.json`：六隻怪獸、棲地示意指數、三段音波與四款新型武器設定
- `docs/design-spec.md`：海報設計規格與資料聲明

## 觀看與下載
開啟 `index.html`，可下載原始 SVG，或使用「下載 4K PNG」按鈕由瀏覽器輸出 3840 × 2160 PNG。

## GitHub Pages
在 GitHub Repository → Settings → Pages → Build and deployment 中選擇 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/(root)`。啟用且部署成功後，預期網站為：
https://cwbdayi.github.io/Ultraman_post/

## 作品聲明
本專案為**非官方粉絲創作**。Ultraman Zero 為既有角色，海報中的角色是全新手工向量風格化描繪；六隻怪獸與四件 ZR 武器均為原創虛構設定。音波、棲地指數與危險等級為劇情示意，不是實際測量資料或官方設定。
