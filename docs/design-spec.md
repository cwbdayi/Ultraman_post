# 海報設計規格 V1.0

- 主角：超人力霸王賽羅（Ultraman Zero）
- 敵人：宇宙咆嘯獸，深藍恐龍與銀黑昆蟲甲殼融合體
- 戰場：巨大星球、太空閃電、能量碰撞、爆炸火光
- 構圖：中景賽羅與怪獸對轟，左側聲波監測、右側棲地雷達與怪獸名錄、下方四張武器卡
- 主標題：超人力霸王賽羅：宇宙決戰
- 標語：當音波撕裂宇宙，英雄必須迎戰。
- 風格：冷色科技／軍事簡報／科幻電影感
- 格式：SVG，3840 × 2160，16:9，4K
- 06:00 低頻、12:00 中頻、21:00 極高頻，僅為示意波形。
- 棲地資料採湖泊 90、海域 75、沙漠 15、沼澤 12 的虛構情境指數；雷達圖不包含城市與山區。
- 六隻原創怪獸與四件原創武器的完整資料見 `data/monster-intelligence.json`。
- 作品註記：非官方粉絲創作，以上怪獸、武器與觀測數據均為虛構。

## 技術
由 SVG 向量插畫製成，無需載入網路圖片，避免無效外鏈；字體依瀏覽器與系統的繁體中文字體替代，建議在臺灣常用中文字體環境觀看；由瀏覽器 Canvas 匯出 4K PNG。
